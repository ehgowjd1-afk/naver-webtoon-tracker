# 로컬 매일 수집 사용법 (내 PC에서 자동 실행)

이 스크립트는 **클라우드(GitHub Actions)로는 못 하는 것** 두 가지를 내 PC에서 처리합니다.

1. **시리즈 순위에 없는 웹툰 연동** — 네이버 시리즈 통합검색으로 작품을 찾아 다운수를 연동 (로그인 없이도 됨)
2. **19금(성인) 작품 다운수 매일 갱신** — 로그인 쿠키가 있을 때만 가능

> 쿠키 없이 실행해도 1번(비성인)은 잘 됩니다. 19금 다운수까지 원하면 아래 쿠키 설정을 하세요.

---

## 1단계 — (선택) 네이버 로그인 쿠키 넣기 *(19금 다운수용)*

**성인인증이 완료된 네이버 계정**으로 로그인한 상태에서:

1. 크롬에서 `series.naver.com` 접속
2. **F12**(개발자도구) → 상단 **Network(네트워크)** 탭 클릭
3. **F5**로 페이지 새로고침
4. 목록 맨 위 `series.naver.com` 요청을 클릭 → **Headers** → **Request Headers**
5. `Cookie:` 뒤에 붙은 **긴 문자열 전체**를 복사
6. `scripts\naver_cookie.txt` 파일을 새로 만들어 붙여넣고 저장

> ⚠️ 이 파일은 **절대 공유·커밋 금지**입니다(내 계정 접근 권한). `.gitignore`에 등록돼 있어 자동으로 깃에 안 올라갑니다.
> 쿠키는 몇 주~달에 한 번 만료될 수 있어요. 19금 다운수가 안 갱신되면 위 과정을 다시 하세요.

---

## 2단계 — 한 번 직접 실행해보기 (확인용)

레포 폴더에서 명령창(PowerShell)을 열고:

```
node scripts\collect_local.js
```

- 마지막에 `저장 완료 …`가 뜨면 성공 (아직 커밋/푸시는 안 함)
- 문제 없으면 자동 실행용으로 넘어갑니다

---

## 3단계 — 매일 자동 실행 등록 (작업 스케줄러)

1. 윈도우 검색 → **작업 스케줄러** 실행
2. 오른쪽 **기본 작업 만들기**
3. 이름: `웹툰 로컬수집` → 다음
4. 트리거: **매일** → 시간은 **오전 10시쯤**(클라우드 수집 9:15 이후) → 다음
5. 동작: **프로그램 시작** → 다음
6. 프로그램/스크립트: **찾아보기**로 `scripts\run_local.bat` 선택 → 다음 → 마침

이제 매일 자동으로 수집→커밋→푸시까지 됩니다.
실행 기록은 `scripts\local_last_run.log`에서 볼 수 있어요.

---

## 참고

- `run_local.bat`은 `node scripts\collect_local.js --push`를 실행합니다(수집 후 자동 푸시).
- `node`가 설치돼 있어야 합니다(명령창에서 `node -v`로 확인).
- 처음 한 번은 시리즈 없던 웹툰 ~700개를 검색하느라 10분쯤 걸리고, 이후로는 새 작품만 검색해서 훨씬 빠릅니다.
- 옵션: `--max=200` 처럼 붙이면 한 번에 새로 검색할 웹툰 수를 제한할 수 있습니다.
