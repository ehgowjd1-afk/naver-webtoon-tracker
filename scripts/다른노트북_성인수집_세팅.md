# 다른 노트북에서 성인 웹툰 수집 돌리기 (Windows)

성인 수집은 **"네이버 로그인 + 연령확인이 된 크롬"** 만 있으면 어느 컴퓨터에서든 됩니다.
(원래 쓰던 PC일 필요 없음 — 그 크롬 세션에서만 성인 페이지가 열리기 때문)

새 노트북에 아래대로 **한 번만** 세팅하면, 이후엔 매일 클릭 2번으로 수집 가능합니다.

> 일반 웹툰은 GitHub 클라우드에서 자동으로 돌아가므로 이 노트북과 무관합니다.
> 안 뜬 날만 폰에서 Run workflow(아래 맨 아래 참고).

---

## 1. 준비물 설치 (최초 1회)

1. **Node.js** — https://nodejs.org → **LTS** 버전 다운로드 후 설치 (기본값으로 다음다음)
2. **Git** — https://git-scm.com/download/win → 설치 (기본값으로)
3. **Chrome** — 이미 있으면 그대로

## 2. 최초 세팅 (한 번만)

**명령 프롬프트(cmd)** 를 열고, 저장할 폴더로 이동 후 (예: `cd %USERPROFILE%\Desktop`) 아래 실행:

```
git clone https://github.com/ehgowjd1-afk/naver-webtoon-tracker.git
cd naver-webtoon-tracker
npm install
```

**깃허브 로그인(푸시 권한)** — 수집 결과를 사이트에 올리려면 필요. 둘 중 하나:

- (쉬움) **GitHub CLI**: https://cli.github.com 설치 → cmd에서 `gh auth login`
  → `GitHub.com` → `HTTPS` → `Login with a web browser` 선택 → 브라우저로 로그인
- 또는 **GitHub Desktop** 설치 → 이 폴더(naver-webtoon-tracker) 를 Add → 계정 로그인

## 3. 매일 수집 (클릭 2번)

1. `naver-webtoon-tracker\scripts\` 폴더에서 **`chrome_debug.bat`** 더블클릭
   → 전용 크롬 창이 열립니다.
   → 그 크롬에서 **네이버 로그인** 하고, **19금(성인) 작품 아무거나 열어 "연령확인"** 완료.

2. 같은 폴더에서 **`collect_adult_cdp.bat`** 더블클릭
   → 자동으로 성인 수집(다운수+회차수) 후 사이트에 반영됩니다.
   → "✅ 진짜 크롬 세션으로 성인 접근 OK" 가 뜨면 정상.
   → 다 되면 "푸시 완료" 표시. 창 닫으면 됩니다.

## 4. 알아두기

- **`chrome_debug.bat` 로 연 크롬만** 사용 (그 창이 9222 포트로 열림). 평소 쓰는 일반 크롬 창은 안 됨.
- 하루에 한 번만 수집됩니다(이미 했으면 "오늘 이미 완료" 스킵).
- **"❌ 아직 성인 접근 안 됨"** 이 뜨면 → 그 크롬에서 19금 작품을 다시 열어 **연령확인**을 하고 `collect_adult_cdp.bat`를 다시 실행. (연령확인은 몇 시간이면 풀릴 수 있음)
- 탭이 멈춰도 스크립트가 자동으로 되살립니다(healPages).
- 매일 다른 시간에 해도 됩니다. 그날 한 번만 하면 그날치가 쌓입니다.

## 5. 일반 웹툰이 안 뜬 날 (수동 실행)

일반은 클라우드에서 하루 3번(09:15·12:15·15:15) 자동으로 돕니다. 혹시 하루도 안 떴으면(저장소에 `auto: 랭킹 자동수집 <날짜>` 커밋이 없으면) 둘 중 편한 걸로 직접 실행:

**A) 이 노트북에서 (세팅 완료 후) — 클릭 1번**
- `scripts\일반웹툰_수동수집.bat` 더블클릭 → 클라우드 수집이 요청됨

**B) 폰에서**
1. `https://github.com/ehgowjd1-afk/naver-webtoon-tracker/actions/workflows/collect.yml`
2. **Run workflow** → Branch `main` → **Run workflow**

→ 둘 다 ~35분 뒤 `auto: 랭킹 자동수집 <날짜>` 커밋이 뜨면 성공.
(일반은 PC 없이 클라우드에서 도는 거라, 성인처럼 크롬을 켤 필요 없음)
