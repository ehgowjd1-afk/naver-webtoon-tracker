# 네이버웹툰 주간 랭킹 트래커

네이버웹툰 앱 **「이번 주 웹툰 랭킹」** 을 매주 기록하는 사이트입니다.
전체 TOP 100 · 여성 TOP 50 · 남성 TOP 50, 순위 변동·연속 기록·신작 진입·성별 취향 온도차를 한눈에.

- **사이트**: https://ehgowjd1-afk.github.io/naver-webtoon-tracker/
- **정적 사이트** (`docs/`, GitHub Pages · `main:/docs`) — 바닐라 HTML/CSS/JS, 프레임워크 없음
- 리디·카카페 트래커와 같은 계정/방식

## 왜 수동 수집인가
이 랭킹은 **앱 전용**이라 자동 스크래핑이 안 됩니다 (게이트웨이 HMAC 인증 + SSL 인증서 고정).
그래서 **매주 앱 스크린샷 → 데이터 추출 → JSON 커밋** 방식으로 기록합니다. 랭킹은 주 1회 갱신이라 주 1회면 충분.

## 매주 업데이트하는 법
1. 앱 「이번 주 웹툰 랭킹」에서 **전체(100) / 여성(50) / 남성(50)** 스크롤 캡처
2. `docs/data/YYYY-MM-DD.json` 파일 추가 (형식은 `2026-08-30.json` 참고)
   - `{ "date","source","charts": { "전체":[…], "여성":[…], "남성":[…] } }`
   - 각 항목: `{ "r":순위, "t":작품명, "a":작가, "m":순위변동(+상승/−하락/0유지), "s":연속주차, "b":[뱃지] }`
   - 뱃지: `신작 · 진입 · 재진입 · 1위탈환 · 완결 · 휴재 · UP`
3. `docs/data/index.json` 의 `weeks` 배열에 날짜 추가하고 `latest` 갱신
4. 커밋·푸시 → GitHub Pages 자동 반영
5. 프론트엔드(css/js)를 고쳤으면 `index.html` 의 `?v=N` 을 올릴 것 (Pages 캐시 회피)

## 데이터
- `docs/data/index.json` — 주차 목록
- `docs/data/YYYY-MM-DD.json` — 주차별 3개 차트 스냅샷

주차가 쌓이면 순위 추이·최장 연속 갱신·재진입 이력 같은 시계열 뷰를 붙일 예정.
